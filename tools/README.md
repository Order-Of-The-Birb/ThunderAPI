# This directory is used for storing tools used by ThunderAPI  
We do not supply these binaries ourselves, you must provide them yourself  
You can get them at the following GitHub repositories:  
- BinBLK: https://github.com/GaijinEntertainment/DagorEngine  
- wt_ext_cli: https://github.com/Warthunder-Open-Source-Foundation/wt_ext_cli  

Just place the downloaded binaries in this directory without changing their names
